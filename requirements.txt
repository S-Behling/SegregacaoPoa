# Multiscale Urban Inequality
Code, processed data, and results for the multiscale analysis of urban inequality in Porto Alegre, Rio Grande do Sul, Brazil.

The project compares different spatial representations of income and measures how the results change across spatial scales.

It also aims to identify which area characteristics are associated with higher or lower sensitivity to spatial aggregation.

# Objective
The pipeline was developed to answer three main questions:
- how income patterns change across different spatial scales;
- where these changes are more pronounced;
- which spatial or socioeconomic characteristics are associated with these changes.

The focus is not only on detecting the effects of spatial aggregation, but also on characterizing and tracking the areas that 
are most sensitive to changes in scale and spatial representation.

# Data
Main source: IBGE Census 2022
Main socioeconomic variable: household income per capita
Spatial data may include: 
 - census sectors;
 - regular grids;
 - aggregated spatial units;
 - administrative boundaries.

Original input files: data/raw/
Processed datasets used by the analysis: data/processed/

# Spatial reference system
Main projected CRS:
- EPSG:31982
- SIRGAS 2000 / UTM zone 22S


# Analysis workflow
1. Data preparation

Cleaning and preprocessing of census and spatial data.

Main tasks:
- load census data;
- standardize column names;
- join socioeconomic and spatial datasets;
- calculate income variables;
- validate geometries;
- convert CRS.

2. Spatial units
Generate or load the spatial representations used in the analysis.

Examples:
census sectors
regular grids
aggregated cells
administrative units

Each configuration should have a unique identifier.

Example:
sector
grid_250m
grid_500m
grid_1000m
grid_2000m

3. Aggregation
Aggregate population and income data to each spatial configuration.
Outputs should preserve the original totals whenever possible.

Basic validation:
total population before aggregation ≈ total population after aggregation

4. Spatial metrics
Calculate metrics for each scale.

Possible outputs include:
 mean income;
 median income;
 variance;
 coefficient of variation;
 Gini coefficient;
 spatial autocorrelation;
 local spatial clusters.

The exact metrics may change during development.

5. Scale sensitivity
Compare the results obtained at different scales.
The goal is to quantify how much each location or spatial pattern changes when the spatial representation changes.

Possible sensitivity measures include:
 absolute difference
 relative difference
 rank change
 cluster change
 class persistence
 local variance across scales

These metrics can be used to identify stable and unstable areas.

6. Area characteristics
Extract characteristics that may help explain scale sensitivity.

Examples:
 population density;
 income heterogeneity;
 local spatial autocorrelation;
 urban density;
 area size;
 shape;
 neighborhood composition;
 proximity to socioeconomic transitions.

The resulting dataset should contain one observation per spatial unit or location, combining sensitivity metrics and explanatory characteristics.

7. Association analysis
Test relationships between scale sensitivity and area characteristics.

Depending on the final model, this step may include:
 correlation analysis
 regression
 spatial regression
 classification
 feature importance
 Output format

Whenever possible, generated datasets should contain fields identifying the analysis configuration.

Example:
 unit_id
 scale
 representation
 income_mean
 income_median
 gini
 moran_i
 cluster
 sensitivity
 population_density
 income_variance

This makes it easier to compare results between experiments.
